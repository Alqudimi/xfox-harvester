# 6) استكشاف الأخطاء وإصلاحها

## أولاً: أين تنظر دائماً

| المكان | ماذا يكشف |
| --- | --- |
| **الأحداث والسجل** في اللوحة | كل قرار اتخذه المحرك مع السبب |
| **الإعدادات ← حالة النظام** | هل المحرك والمتصفح والقاعدة سليمة؟ |
| سجل التشغيل الكامل (صفحة المهمة) | خرج X-CrawlFox الخام سطراً سطراً |
| `data/logs/xfox_*.log` | سجل الخادم التفصيلي |

## المشاكل الشائعة

### 1) «متصفح Camoufox: غير مثبت» في حالة النظام

```bash
camoufox fetch          # داخل البيئة الافتراضية (.venv) أو الحاوية
```

- فشل التنزيل بخطأ GitHub 403؟ حد معدل مؤقت — انتظر ساعة أو استخدم شبكة أخرى.
- داخل Docker: الامتداد يُنزَّل أثناء البناء؛ أعد البناء `docker compose build --no-cache xfox`.

### 2) نتيجة التشغيل «خطأ متصفح Camoufox»

- متصفح غير منزّل (انظر أعلاه).
- مكتبات النظام ناقصة (تثبيت مباشر على خادم بلا Docker): ثبّت `libgtk-3-0 libdbus-glib-1-2 libxt6 libasound2`.
- الذاكرة أقل من ~1GB للمتصفح — ورفّع موارد الخادم أو خفّض `max_concurrent_runs` إلى 1.

### 3) نتيجة «انتهت الجلسة — أعد رفع الكوكيز»

- الكوكيز انتهت (X يُنهي الجلسات الدوّارة كل فترة). الحل: أعد رفع كوكيز حديثة ثم «اختبار الحساب».
- تكرارها 3 مرات متتالية يجعل الحساب «غير صالح» تلقائياً — الرفع الجديد يعيد تفعيله.
- تأكد أن التصدير من صفحة **x.com** نفسها وليس موقعاً آخر.

### 4) نتيجة «قيود معدل من X»

- المحرك بردّ فعله تلقائياً (تهدئة الحساب + خفض الوتيرة). خفّف أنت أيضاً:
  - ارفع «أدنى فجوة» و「الفترة الدورية»، أو استخدم وتيرة **حذر**.
  - فعّل نافذة النشاط، ووزّع على حسابات أكثر (كل حساب = مسار منفصل).
- تكررها يعني الوتيرة أعلى مما يحتمله حسابك — عامل الحساب كأنه بشري فعلاً.

### 5) التشغيل «تم تجاوزه — لا حساب متاح»

كل الحسابات في تهدئة/معطّلة/بلا كوكيز أو بلغت السقف اليومي — راجع عمود «الحالة» في صفحة الحسابات وانتظر انتهاء التهدئة (يظهر عدّادها).

### 6) «نتيجة فارغة» مع أن الحساب سليم

- في مراقبة الحسابات مع «الجديد فقط»: لا منشورات جديدة بعد آخر معرّف محفوظ — طبيعي تماماً.
- في البحث: كلمات نادرة جداً، أو الخلاصة لم تحمّل — أعد التشغيل مرة.
- إن تكررت مع كل المهام فقد يكون خنقاً ناعماً؛ خفّف الوتيرة.

### 7) فشل الاتصال بقاعدة البيانات

- تحقق من `XFOX_DATABASE_URL` في `.env` ثم `alembic upgrade head`.
- Docker: `docker compose logs postgres` — تأكد أن القاعدة healthy قبل التطبيق.
- امتداد trigram (بحث أسرع) اختياري؛ إن رفض المضيف إنشاءه يعمل البحث عادياً (أبطأ فقط).

### 8) البث الحي لا يعمل

- SSE يحتاج بروكسي لا يُخزّن مؤقتاً: عطّل `proxy_buffering` في Nginx (انظر دليل التثبيت).
- الشبكات المؤسسية: قد تُقطع الاتصالات المفتوحة — الواجهة تُعيد الاتصال تلقائياً.

### 9) تصدير Excel يظهر العربية رموزاً؟

الملفات مولّدة بترميز UTF-8 (وCSV بـ BOM) — افتحها من **Data → From Text/CSV** واختر UTF-8، أو استخدم ملف XLSX مباشرة.

### 10) نسيت كلمة مرور المدير

لا يوجد مستخدمون آخرون؟ الحل الأنظف عبر قاعدة البيانات مباشرة:

```bash
python - <<'EOF'
from pwdlib import PasswordHash
print(PasswordHash.recommended().hash("NewPass123!"))
EOF
# ثم: UPDATE app_users SET password_hash='<الناتج>' WHERE username='admin';
```

## أعادة الضبط الكاملة (بيانات تطوير)

```bash
# القاعدة
psql "$DATABASE_URL" -c 'DROP SCHEMA public CASCADE; CREATE SCHEMA public;'
alembic upgrade head
# البيانات والكوكيز
rm -rf data/
```
