# 4) دليل الاستخدام

## أول تشغيل

1. افتح `http://localhost:8000` — ستظهر شاشة **إنشاء المدير** (تظهر مرة واحدة فقط).
2. سجّل الدخول. الجلسة تدوم 7 أيام (كوكي JWT آمن).

## لوحة القيادة

- **بطاقات**: إجمالي المنشورات، المؤلفون، الحسابات النشطة، المهام النشطة.
- **صف اليوم**: تشغيلات اليوم، الناجحة، والمنشورات الجديدة.
- **رسم 14 يوماً**: وتيرة الحصد اليومية.
- **البث الحي**: آخر أحداث النظام مباشرة (SSE).
- **لافتة الخطر**: تظهر كأحمر عند إيقاف المحرك مع زر «إقرار واستئناف» (للمدير/المشغل).

## حسابات X

كل صف = حساب حصده معزول. الأعمدة: الحالة (نشط/تهدئة/معطّل/غير صالح)، الصحة (شريط 0–100)، الكوكيز، التشغيلات، المحصود، البروكسي، آخر تشغيل.

### إضافة حساب وربط كوكيزه

1. **إضافة حساب** → تسمية (مثل: «حساب البحث الرئيسي») واختيارياً بروكسي.
2. زر 🔑 (الكوكيز) → اتبع الخطوات الأربع المعروضة:
   - ثبّت إضافة [Cookie Editor](https://cookie-editor.com) في متصفحك.
   - سجّل الدخول إلى x.com.
   - Cookie Editor → **Export** → **JSON** وانسخ.
   - الصق في المربع واضغط **تثبيت**.
3. زر ⚗ (اختبار الحساب): يشغّل حصداً حقيقياً مصغراً (منشور واحد من @x) ويعيد النتيجة — أسرع طريقة للتأكد أن الجلسة صالحة.

> عند «غير صالح» بعد انتهاء الجلسة: أعد رفع الكوكيز فقط — يُفعَّل الحساب تلقائياً.

## البروكسيات (مشغل+)

أضف بروكسي (`http://user:pass@host:port` أو `socks5://host:port`)، اربطه بحساب من صفحة الحسابات، وافحصه بزر الفحص (قياس استجابة عبر الوصول إلى x.com). البروكسي المعطّل يُستبعد تلقائياً من التشغيلات.

## مهام الحصد

### أنواع المهام

| النوع | ماذا يفعل | مثال استخدام |
| --- | --- | --- |
| **بحث** | كلمات مفتاحية (حتى 20) بكتابة بشرية + تبويب Latest | رصد موضوع/علامة |
| **مراقبة** | حسابات محددة، تزايدياً — الجديد فقط | متابعة منشورات نافذين |
| **خط زمني** | خلاصتك Following/For you | أرشفة خلاصتك |
| **أخبار اليوم** | شريط الأخبار + ملخصات Grok (وضع التعميق) | رصد الأخبار |
| **مركّبة** | أي مزيج من أعلاه في جلسة واحدة | تشغيل صباحي شامل |

### معالج الإنشاء (5 خطوات)

1. **النوع** + الاسم.
2. **الإعدادات** حسب النوع (كلمات، حسابات، تبويبات، حدود…).
3. **الجدولة**: يدوي / دوري (≥15 د) / يومياً في وقت محدد + الأولوية.
4. **سياسة الأمان**: حذر / متوازن / سريع + تثبيت على حساب محدد (أو توزيع تلقائي).
5. **المراجعة**: ملخص JSON للإعدادات قبل الإنشاء.

### إدارة المهام

من الجدول: ⚡ تشغيل الآن، ⏸ إيقاف مؤقت، ▶ استئناف، ✕ حذف. اضغط اسم المهمة لصفحة التفاصيل:

- إحصاءات + التشغيل القادم.
- **السجل الحي**: طرفية تُبَث أثناء التشغيل (سطر بسطر من X-CrawlFox).
- **سجل التشغيلات**: الحالة، الجديد/الإجمالي، المدة، التصنيف (قيود معدل؟ جلسة منتهية؟…)، وكل سجل كامل عند الطلب.
- إلغاء تشغيل جارٍ (يقتل المتصفح فوراً ويحفظ الحالة).

## المنشورات

- **بحث فوري** في النص/الوصف/المؤلف (يدعم العربية والإنجليزية).
- فلاتر: مؤلف، مصدر، نطاق تاريخ، أدنى إعجابات/مشاهدات، وسائط، وترتيب بأي عمود.
- كل صف: مؤلف، مقتطف، إعجابات/مشاهدات، المصدر، وقت النشر، ورابط فتح في X.
- **التصدير**: CSV (بترميز يدعم العربية في Excel) / JSON / Excel — يطبّق الفلاتر الحالية، والملف يظهر في قائمة التصديرات للتنزيل.

## المؤلفون

دليل كل المؤلفين المحصودين مع عدد منشوراتهم وأول/آخر ظهور وبحث.

## الأحداث والسجل

شريط مباشر أعلى الصفحة + سجل تاريخي قابل للتصفية (مستوى، فئة، بحث) — كل قرار من المحرك موثق هنا: تهدئة حساب، تغيير خطر، تراجع مهمة، دخول مستخدم… إلخ.

## الإعدادات (مدير)

- **حالة النظام**: محرك X-CrawlFox، متصفح Camoufox، القاعدة، المساحة، مدة التشغيل.
- **سياسات الحماية**: كل قيمة موصوفة بنص مساعدة (انظر دليل الحماية).
- **أوقات النشاط، عتبات المخاطر، إعدادات المحرك، الاحتفاظ**.
- **الصيانة**: تنظيف الأحداث/التشغيلات القديمة.
- **منطقة الخطر**: حذف كل البيانات المحصودة (لا يمس الحسابات).

> كل تعديل يسري على المحرك **فوراً** دون إعادة تشغيل.

## المستخدمون (مدير)

إضافة مستخدمين بأدوار (مدير/مشغل/مشاهد)، تغيير الأدوار، تعطيل/تفعيل، تغيير كلمات المرور، حذف. حمايات مدمجة: لا يمكنك حذف نفسك أو تخفيض دورك.

## اللغة

زر **English/عربي** في الشريط العلوي يبدّل فوراً (يُحفظ اختيارك محلياً) — عربية RTL افتراضياً.
